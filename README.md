# Interpretability in Vision-Language Models

Research project exploring interpretability in Vision-Language Models (VLMs), conducted as part of the M.Sc. Data Science & Artificial Intelligence program at Université Côte d'Azur.

## Overview

Vision-Language Models combine visual and textual information to perform multimodal tasks. Understanding how these models process information, form predictions, and represent relationships between modalities in medicine remains an important research challenge.

**Research objectives:**
- Review existing interpretability methods for VLMs.
- Find Research Question
- Implement and evaluate selected baseline approaches.
- Investigate remaining Interpretability of a medical specialised model compared to the unspecified version.
- Compare interpretability methods through reproducible experiments.
